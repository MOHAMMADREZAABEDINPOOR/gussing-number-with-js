## شروع کار

مرورگر جدید؛ Python فقط برای سرور HTTP محلی اختیاری است.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/gussing-number-with-js.git
cd gussing-number-with-js

python -m http.server 8000
```
